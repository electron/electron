Use Selection for Find

Select a word in this paragraph and press Cmd+E to use it as the search text, then press Cmd+G to jump to the next match. Switch to another app such as Safari or TextEdit and press Cmd+G there: it searches for the same text, because it was shared through the macOS find pasteboard.
